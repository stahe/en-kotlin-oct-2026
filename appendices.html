    15.1. SGBD MySQL with Laragon

    Chapters 10 and 11 of this document use SGBD MySQL 8. The easiest way to install it on Windows is to install Laragon, a portable development environment that includes MySQL, the graphical client HeidiSQL, a configured terminal, Apache, and PHP. The author also uses it for his courses PHP.

    15.1.1. Installation

    Laragon can be downloaded from https://laragon.org. The installation is standard; you can use the suggested installation folder ([C:\laragon]). Laragon provides MySQL 8 (the exact version depends on the Laragon version), with a [root] administrator account that has no password and a server listening on port 3306 on the local machine. This is the configuration assumed by the examples in the document, where the URL and JDBC are of the form:

    1
    jdbc:mysql://localhost:3306/dbarticles

    with the username [root] and an empty password. If MySQL was installed differently, with a password for [root], you must update the examples accordingly ([.properties] files or constants at the top of the programs).

    For a system without Laragon, you can also install MySQL Community Server from https://dev.mysql.com/downloads/mysql/, or its open-source derivative, MariaDB. However, the examples have only been tested with MySQL 8: the scripts in Chapter 10 use a collation specific to MySQL 8 ([utf8mb4_0900_ai_ci]), and with MariaDB, it would need to be adapted, as would the driver JDBC (MariaDB provides its own).

    15.1.2. Starting and Stopping MySQL

    The Laragon main window includes a “Start All” button that starts the servers (Apache and MySQL) and a “Stop” button that stops them. MySQL is not a Windows service that runs at system startup: it only runs when started from Laragon, which prevents it from consuming resources when not in use. The Laragon menu (right-click in the window) also allows you to start only MySQL and to choose its version.

    When MySQL is not running, the programs in Chapters 10 and 11 fail with an exception from the JDBC driver indicating that no connection could be established ([CommunicationsException]: “Communications link failure”): this is the first thing to check in case of an error.

    15.1.3. The command-line client

    Laragon’s Terminal button opens a terminal where Laragon commands are accessible, including the command-line client MySQL ([mysql]). To connect to the server, use:

    1
    > mysql -u root

    Then enter the commands SQL, each ending with a semicolon ([show databases;], [use dbarticles;], [select * from articles;]) and [exit] to exit. The client can also run a script SQL, which is what Chapter 10 does to create its databases:

    1
2
3
    > cd kotlin-oct-2026\10-jdbc\sql
> mysql -u root < dbarticles.sql
> mysql -u root < dbimpots.sql

    The scripts completely recreate their database each time they are run: you can rerun them to restore the data to its initial state after testing.

    15.1.4. The HeidiSQL graphical client

    The Laragon Database button launches the graphical client HeidiSQL. Upon first launch, HeidiSQL offers a connection session that is already configured for the Laragon server MySQL (host [127.0.0.1], user [root], blank password, port 3306); simply open it. You will see:

    • on the left, the tree view of the server’s databases and their tables;
    • on the right, tabs showing a table’s structure, its data (which can be edited directly), and a field for entering SQL queries (the “Query” tab), which are executed by [F9].

    To create a database using a script from Chapter 10, open the script (via the “File” menu, using the command to load a file: SQL) in a query tab, then execute it ([F9]). You can also create a database, a user, and user permissions using the menus in HeidiSQL (right-click on the connection / “Create New” / "Database"; "Tools" menu / "User Manager"), but the SQL scripts have the advantage of being reproducible and able to be rerun.

    IntelliJ IDEA can also connect to a database via its “Database” window: there you can view the tables and their data, and you can execute queries (SQL) without leaving IDE.
